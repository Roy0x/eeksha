WORKFLOW

From sensor data to reviewable artifacts.

01 / Reconstruct

Use aligned RGB images, depth maps and explicit measured camera calibration to produce metric XYZ point clouds.

02 / Annotate and review

Manually label scenes, resume brush corrections, and compare human label disagreement. Review is not ground-truth certification.

03 / Audit and export

Inspect depth coverage, class counts, provenance and limitations; export PLY, NPZ, and JSON quality reports.

TRY THE ACTUAL PRODUCT

Run the dataset workspace on your machine.

The complete processing tool currently runs locally with Python. Public uploads are not supported by this research preview.

git clone https://github.com/Roy0x/eeksha.git
cd eeksha
git switch feat/eeksha-ci-repro-20261113
python -m pip install -r requirements.txt
python webapp.py

Then visit http://127.0.0.1:8022/workspace.
